# Task-7_Elavate_labs
Description

This task focuses on identifying and removing suspicious or unnecessary browser extensions. The goal is to improve browser security, protect user privacy, and enhance overall browser performance.

Tool Used

Google Chrome (Extensions Manager)

What Was Done

Reviewed all installed browser extensions

Checked extension permissions, reviews, and usage

Identified unused or suspicious extensions

Removed unsafe or unnecessary extensions

Restarted the browser and checked performance

Outcome

After removing suspicious extensions, browser performance improved and unwanted ads were reduced. This task shows the importance of regularly managing browser extensions to maintain security and privacy.
